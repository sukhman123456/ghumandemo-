# Ghumans Kitchen Express 🍔🍕☕

> **Good Food. Happier People.**  
> Punjab's premier double-decker pure vegetarian food truck and roadside dining experience stationed prominently on the historic **Grand Trunk Road (NH 44), Adjacent to Dhilwan Toll Plaza, Punjab 144804**.

---

## 🌟 Overview & Highlights

- **100% Pure Vegetarian Integrity**: Dedicated clean griddles, zero meat, certified culinary hygiene.
- **Iconic Double-Decker Architecture**: Ground-floor open express kitchen with second-floor open-air rooftop glass deck seating with warm evening fairy lights.
- **Prime Highway Position**: Located right on the Jalandhar to Amritsar corridor (24 KM from Jalandhar, 56 KM from Amritsar) next to Dhilwan Toll with free car & bus parking.
- **Gourmet Highway Menu**:
  - Stone-Baked Farmhouse & Paneer Makhani Pizzas
  - Sizzling Double-Decker Paneer & Aloo Herb Burgers
  - Tandoori Paneer Tikka & Mexican Salsa Wraps
  - Loaded Cheesy & Peri-Peri Crinkle Fries
  - Belgian Chocolate Thick Shakes & Iced Frappes
  - Authentic Steaming Clay-Pot Kulhad Chai

## 🛠️ Built With

- **Framework**: [TanStack Start](https://tanstack.com/start) & React 19
- **Bundler & Server**: Vite & Nitro
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Icons**: Lucide React
- **Animations**: CSS Transforms & Micro-animations
- **Platform**: Built with [Lovable](https://lovable.dev)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/sukhman123456/ghumandemo-.git
cd ghumandemo-

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:8080](http://localhost:8080) to preview the experience locally.
